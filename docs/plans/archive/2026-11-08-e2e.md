# E2E 測試（Playwright）

## 目標

在真實瀏覽器中，對 docker compose 環境（nginx、後端、PostgreSQL）走完主要流程，取代 `docs/TESTING.md` 的手動端到端驗證，作為之後新功能的回歸保護。

## 流程

| 測試 | 內容 |
|---|---|
| 前台購物 | 行程頁 → 加入購物車 → 套用優惠碼 → 填寫資料 → 送出訂單 → 成功頁付款 |
| 後台產品 | 登入 → 新增產品（啟用）→ 前台看得到 → 後台刪除 → 前台看不到 |
| 後台訂單 | 前台下單 → 後台訂單列表看得到 → 修改付款與外送狀態 |

## 做法

- `e2e/`：獨立的 `package.json`（`@playwright/test`），只用 Chromium。
- 購物車全站共用，測試依序執行（`workers: 1`），每個測試開始前清空購物車。
- 測試建立的資料加上唯一標記（時間戳），不依賴執行順序。
- `npm run e2e`（`scripts/e2e.sh`）：啟動**獨立的環境**（專案名稱 `travfree-e2e`、連接埠 8100／5433、全新的資料庫 volume）→ 匯入種子 → 執行測試 → 刪除整套環境。平常的 `:8000` 不受影響。
- `docker-compose.yml` 的資料庫連接埠與 volume 名稱改為可用環境變數指定，預設值不變。

## CI

Docker compose job 在備份與還原之後，對同一套環境執行 E2E。失敗時上傳 Playwright 報告（截圖、錄影、trace）。
