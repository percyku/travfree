# 優惠券與付款 UI

## 目標

處理 `ARCHITECTURE.md` 前端已知限制的最後一項：前端沒有優惠券與付款的 UI。API 與 spec 已完成，這次只改前端。

## 決定（2026-11-08 與使用者確認）

### 後台優惠券管理

- 後台導覽列新增「優惠券列表」，路由 `/admin/coupons`，列表、新增、編輯、刪除比照產品頁。
- 折扣欄位直接輸入 `percent`（**實付比例**，0–100），旁邊即時顯示換算的折數（80 → 8 折）。
- 到期日用 `<input type="date">`，有效到當天 23:59:59（本地時間），送出時換成 Unix **秒**。
- 錯誤（`code 已存在`、`percent 必須介於 0 到 100` 等）顯示後端回傳的原因。

### 前台套用優惠券

- 購物車頁的「費用明細」加上優惠碼輸入框與「套用」按鈕，手機版的明細也要有。
- 明細拆成：原價小計、商品特價折抵（`原價小計 − total`）、優惠券折抵（`total − final_total`）、總計（`final_total`）。
- 套用後顯示目前的優惠碼（從品項的 `coupon` 讀取）。spec 規定之後加入的品項不帶優惠，提示文字要說明。

### 前台付款

- 訂單成功頁顯示付款狀態：未付款時有「立即付款」按鈕，呼叫 `POST /pay/{id}` 後重新讀取訂單；已付款時顯示付款時間（`paid_date` 是 Unix **秒**）。
- 不新增頁面，之後用同一個網址回來也能付款。

## 步驟

1. `orderSlice` 加上付款 thunk；`cartSlice` 加上套用優惠券 thunk。
2. 購物車頁：優惠碼輸入、明細拆分（桌面與手機）。
3. 訂單成功頁：付款狀態與付款按鈕。
4. 後台：`AdminCoupons`、`AdminCouponModal`、`AdminCouponTable`，路由與導覽列。
5. `npm run lint`、`npm run build`，請使用者在瀏覽器測試。
6. 文件：`FEATURES.md` 狀態表、`ARCHITECTURE.md`（頁面路由、已知限制）、`CHANGELOG.md`。
